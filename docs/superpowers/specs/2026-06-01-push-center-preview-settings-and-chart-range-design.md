# Push Center 全宽预览、设置弹窗与宽基指数时间范围设计

## 1. 背景与目标

Push Center 的 `Schedules` 页面当前同时展示计划任务编辑、投递配置和日报预览。配置区占用较多空间，预览区域无法充分利用页面宽度。宽基指数图表当前固定展示最近三个月，也无法按推送场景调整历史区间。

本次改动目标：

1. 将计划任务和投递配置收纳到设置弹窗。
2. 让 `Schedules` 页面主体仅展示全宽日报预览。
3. 为宽基指数图表新增 `3个月`、`6个月`、`1年`、`2年`、`3年` 五档时间范围。
4. 默认推送最近 `1年` 宽基指数图表。
5. 历史数据库保留已获取的全部数据；展示时仅按当前范围裁剪。
6. 点击全量刷新时，按当前选择范围拉取并补齐历史数据。

## 2. 已确认方案

采用单一配置源方案：在 Push Center 配置中新增 `market_chart_range` 字段。

允许值：

| 配置值 | 展示文案 | 自然日窗口 |
| --- | --- | --- |
| `3m` | 3个月 | 92 天 |
| `6m` | 6个月 | 183 天 |
| `1y` | 1年 | 366 天 |
| `2y` | 2年 | 731 天 |
| `3y` | 3年 | 1096 天 |

旧配置缺少 `market_chart_range` 时，后端归一化为 `1y`，前端 adapter 也使用 `1y` 作为兼容默认值。

该字段统一作用于：

- 页面预览
- 手动发送
- 定时发送
- 宽基指数全量刷新

## 3. 页面设计

### 3.1 Schedules 页面

`Schedules` 页面主体仅渲染一个全宽 `Push preview` 卡片，不再展示独立的左侧配置栏。

预览卡片右上角包含：

- 时间范围下拉框：显示 `3个月`、`6个月`、`1年`、`2年`、`3年`
- 设置按钮：使用 Heroicons 齿轮图标
- 全量刷新图表按钮：使用 Heroicons 循环刷新图标
- 刷新预览按钮：使用 Heroicons 文档刷新图标
- 立即发送按钮：使用 Heroicons 纸飞机图标

四个操作按钮使用可区分的图形，并仅显示图标，减少窄屏占用。每个按钮必须提供：

- `aria-label`
- `title` 悬停提示
- 键盘可见焦点状态
- 禁用状态

按钮容器允许自动换行，避免移动端或窄窗口溢出。

### 3.2 设置弹窗

点击齿轮按钮打开设置弹窗。弹窗包含：

1. 计划任务编辑器
2. 投递配置表单
3. 保存配置按钮
4. 保存成功或失败提示

弹窗不再包含：

- 刷新预览按钮
- 立即发送按钮
- 宽基指数全量刷新按钮

弹窗应支持内容滚动，并提供关闭按钮。关闭弹窗不会丢失当前草稿；重新打开时继续展示未保存编辑内容。

### 3.3 History 页面

`History` 标签页保持现有行为，仅展示执行记录，不加载日报预览，不展示设置弹窗入口。

## 4. 前端组件边界

### 4.1 `PushPage`

`frontend/src/pages/push-page.tsx` 继续持有 Push Center 工作区状态：

- `draft`
- `preview`
- `recentRuns`
- `flash`
- `chartRefreshJob`
- 设置弹窗开关状态

`Schedules` 标签页改为直接渲染全宽 `PushPreviewPanel`。`PushSchedulesEditor` 和 `PushConfigForm` 作为设置弹窗内容渲染。

### 4.2 `PushPreviewPanel`

`frontend/src/features/push/components/push-preview-panel.tsx` 增加以下输入：

- 当前宽基指数时间范围
- 时间范围选项
- 切换时间范围回调
- 打开设置弹窗回调
- 刷新预览回调
- 立即发送回调
- 对应加载状态

范围切换后更新草稿，并立即请求预览重绘。范围切换不会自动触发外部历史抓取。

### 4.3 设置弹窗组件

新增独立设置弹窗组件，负责：

- 弹窗语义和遮罩层
- 标题和关闭按钮
- 可滚动内容区
- 组合现有 `PushSchedulesEditor`
- 组合现有 `PushConfigForm`

`PushConfigForm` 缩减为编辑表单和保存配置按钮，不再承担刷新预览和立即发送操作。

## 5. 配置契约

Push 配置新增字段：

```json
{
  "market_chart_range": "1y"
}
```

完整结构中的位置：

```json
{
  "config": {
    "selected_module_ids": ["market"],
    "report_style": "newspaper",
    "market_chart_range": "1y",
    "email": {},
    "schedules": []
  }
}
```

后端配置归一化要求：

1. 缺失字段时使用 `1y`。
2. 非法值快速失败，不静默回退。
3. 保存配置后持久化该字段。
4. 对外公开配置、前端 adapter 和 TypeScript 类型同步更新。

## 6. 宽基指数数据流

### 6.1 预览与发送

报告服务根据 `market_chart_range` 裁剪图表点位：

1. 获取卡片中可用的完整历史点位。
2. 使用最新交易日作为锚点。
3. 按配置对应的自然日窗口过滤。
4. 渲染标题、摘要和 SVG 可访问性文案时使用对应范围文案。

例如：

- `3m`：`3M Trend`、`近3个月趋势`
- `1y`：`1Y Trend`、`近1年趋势`
- `3y`：`3Y Trend`、`近3年趋势`

页面预览、手动发送和定时发送必须继续复用同一份 HTML 报告生成逻辑，避免所见即所得链路再次分叉。

页面操作与持久化边界：

- 范围切换、刷新预览、全量刷新和立即发送使用当前页面草稿。
- 保存配置后，草稿中的 `market_chart_range` 写入 JSON 配置。
- 定时发送读取已保存配置，因此只使用最近一次保存的范围。

### 6.2 全量刷新

点击全量刷新图表时：

1. 前端提交当前草稿配置。
2. Push Center 服务读取 `market_chart_range`。
3. Dashboard 服务将范围对应窗口传给市场监控服务。
4. 市场 provider 按该窗口读取历史。
5. 市场监控服务逐指数汇报进度。
6. SQLite 对返回点位执行按日期 `upsert`。
7. 保留当前范围外已有历史，不删除旧行。
8. 刷新结束后按当前范围重绘预览。

### 6.3 数据保留

不再使用最近 92 天窗口替换策略删除数据库历史点。历史库保留所有已获取点位，便于后续切换到更长范围时复用。

上游刷新结果只覆盖当前范围时：

- 当前范围内返回的同日期点位更新为最新值。
- 当前范围外历史保持不变。
- 上游未返回的旧日期点也保留，不做删除。

## 7. 异常处理

### 7.1 配置校验

- 后端仅接受 `3m | 6m | 1y | 2y | 3y`。
- 非法范围值返回现有 Push 控制接口的友好错误响应。
- 日志记录必要上下文，但不记录 SMTP 密码等敏感信息。

### 7.2 上游异常

全量刷新按指数独立执行：

- 某一指数拉取失败时，保留该指数已有历史。
- 某一指数只返回短序列时，仍可按日期 `upsert` 可用点位，不删除旧数据。
- 进度弹窗展示局部失败或保留旧历史的提示。
- 其他指数继续刷新。

### 7.3 前端状态

- 刷新预览、立即发送和全量刷新期间，对应按钮进入禁用状态。
- 设置弹窗保存失败时保留草稿并展示错误提示。
- 图表刷新完成后更新预览；出现警告时保留可用预览并展示警告状态。

## 8. 测试策略

### 8.1 前端测试

覆盖：

1. `Schedules` 页面仅展示全宽预览，不再直接展示配置表单。
2. 齿轮按钮打开设置弹窗。
3. 弹窗包含计划任务、投递配置和保存按钮。
4. 弹窗不包含刷新预览和立即发送按钮。
5. 预览页存在五档范围下拉，默认选择 `1y`。
6. 四个图标按钮包含 `aria-label` 和 `title`。
7. 切换范围会更新草稿并触发预览请求。
8. 全量刷新请求携带当前范围。
9. 手动发送请求携带当前范围。

### 8.2 后端测试

覆盖：

1. 旧配置缺少 `market_chart_range` 时默认归一化为 `1y`。
2. 保存配置后持久化合法范围。
3. 非法范围快速失败。
4. 全量刷新把当前范围传递到 provider。
5. 历史刷新仅执行 `upsert`，不删除范围外历史。
6. 报告服务按五档范围裁剪点位。
7. 报告标题、摘要和 SVG 文案随范围变化。
8. 预览、手动发送和定时发送复用同一范围配置。
9. 上游短序列和局部失败不会清空已有历史。

## 9. 回归清单

1. 原功能验证点：配置保存、预览刷新、立即发送、定时发送、执行历史、图表刷新进度仍可用。
2. 新功能验证点：全宽预览、设置弹窗、五档范围下拉、默认 `1年`、按当前范围全量刷新。
3. 边界情况：旧配置缺字段、范围切换后未保存、短历史、局部上游失败、窄屏按钮换行。
4. 异常处理：非法范围、预览失败、发送失败、刷新失败均展示友好提示并保留草稿或已有历史。
5. 配置兼容性：旧 JSON 配置无需人工迁移，读取时自动补齐 `market_chart_range: "1y"`。
