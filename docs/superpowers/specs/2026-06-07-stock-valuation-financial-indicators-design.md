# 股票估值与财务质量指标设计

## 目标

在股市目录的单只股票详情页补充两组历史指标：

- 日频估值指标：PE(TTM)、PB(MRQ)、股息率(TTM)、总市值。
- 季度财务指标：ROE、营收同比、净利润同比、资产负债率。

日频指标与 K 线共用日期范围并显示在行情图右侧图例；季度指标复用现有
`market_stock_financial_metric` 表和财务数据页签。

ETF 不采集公司估值和财务分析指标，字段保持为空并沿用现有空状态。

## 方案选择

### 方案 A：扩展现有日线表与财务指标表

在 `market_stock_daily_bar` 增加四个可空列；季度指标继续以指标行写入
`market_stock_financial_metric`。详情接口沿用现有 `daily_bars` 和
`financials.series` 结构。

优点是查询链路最短、接口改动小、图表可直接按日期对齐。缺点是 210 个日线分片都要执行
兼容迁移。

### 方案 B：新增独立估值历史表

估值指标单独建表，详情查询时与日线按日期合并。

优点是估值数据与 OHLCV 解耦。缺点是增加跨表读取、日期对齐和同步状态管理，且不符合本次
明确要求的 `market_stock_daily_bar` 存储位置。

### 方案 C：只在接口层实时获取

每次打开详情时从上游读取指标，不做持久化。

优点是无需迁移。缺点是页面受上游稳定性影响、无法离线使用，也不满足按日和按季度存储要求。

采用方案 A。它符合现有分片架构和用户指定的表边界，且保持 Controller、Service、
Repository 分层不变。

## 数据模型

### 日线分片

每个分片的 `market_stock_daily_bar` 增加：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `pe_ttm` | `REAL NULL` | 滚动市盈率，单位为倍 |
| `pb_mrq` | `REAL NULL` | 最近报告期市净率，单位为倍 |
| `dividend_yield_ttm` | `REAL NULL` | 滚动股息率，单位为 `%` |
| `total_market_cap` | `REAL NULL` | 总市值，库存单位为元 |

四列允许为空，避免某个指标缺失时丢弃当天 OHLCV。初始化分片时通过 `PRAGMA table_info`
检查并幂等执行 `ALTER TABLE ADD COLUMN`，兼容现有 210 个数据库和运行时自愈建库。

主键仍为 `(symbol, trade_date)`，不新增索引；现有按 symbol 和日期范围查询已经覆盖读取路径。

### 财务指标

`market_stock_financial_metric` 不改 schema，新增以下 `metric` 值：

| metric | label | unit |
| --- | --- | --- |
| `roe` | ROE | `%` |
| `revenue_yoy` | 营收同比 | `%` |
| `net_profit_yoy` | 净利润同比 | `%` |
| `debt_asset_ratio` | 资产负债率 | `%` |

指标按报告期存储。季度页面请求 `quarterly` 时展示所有非年末报告期；年度请求 `yearly`
时仍可展示年末值，保持现有季度/年度切换兼容。

## 数据同步

### 日频估值

新增估值加载器，默认使用 AkShare 东方财富估值分析端点 `stock_value_em`，读取
PE(TTM)、PB(MRQ) 和总市值。股息率(TTM) 使用 AkShare 东方财富分红送配详情端点
`stock_fhps_detail_em`：只统计方案进度为已实施且具有除权除息日的现金分红，将
“每 10 股派息”除以 10 得到每股现金分红；对每个交易日汇总其前 365 个自然日内已除息的
每股现金分红，再除以当天收盘价并乘以 100。

若分红源暂时不可用，只将 `dividend_yield_ttm` 保持为空，不阻断另外三项和 K 线同步。

同步指定行情窗口时：

1. 先正常读取 OHLCV 并计算均线。
2. 独立读取估值历史和分红事件。
3. 按交易日期左连接估值历史，并基于收盘价计算当日股息率(TTM)。
4. 将总市值以元写库，接口返回时换算为亿元。
5. 任一附加数据源失败时记录短告警并继续写入 OHLCV。

手动刷新与首次懒加载均执行同一流程，保证后续增量刷新可补齐历史空值。

### 季度财务指标

新增财务分析加载器，默认使用 AkShare 东方财富主要财务指标端点
`stock_financial_analysis_indicator_em`。解析报告期和四个百分比字段，与利润表、
现金流量表、资产负债表抽取结果合并后统一 upsert。

财务分析源失败时保留现有五项财务指标同步结果并记录告警；单项缺失不生成零值。

## 接口契约

详情接口每个 `daily_bars` 项新增可空字段：

```json
{
  "pe_ttm": 5.12,
  "pb_mrq": 0.48,
  "dividend_yield_ttm": 3.26,
  "total_market_cap": 2130.77
}
```

`total_market_cap` 的接口单位为亿元。其他三项分别使用“倍、倍、%”。

`financials.series` 增加四个序列，沿用 `{ metric, label, points }`，每个点的单位为 `%`。
现有字段只增加不删除，旧前端可忽略新增字段。

## 前端展示

### 行情页

K 线图增加 PE、PB、股息率、总市值四个折线序列。图例固定在图表右侧，K 线和均线图例也
统一放入右侧滚动图例。为了避免不同量纲压缩价格：

- K 线与均线使用左侧价格轴。
- PE、PB、股息率和总市值使用隐藏的独立数值轴。
- 用户可通过图例开关单项指标。
- 缺失值使用 `null`，ECharts 不跨缺口伪造数据。

图表保留标题语义化 `aria-label`，tooltip 显示指标单位，总市值格式化为亿元。

### 财务页

四个新指标加入现有财务二级页签，顺序放在原有五项之后：

1. ROE
2. 营收同比
3. 净利润同比
4. 资产负债率

图表继续一次展示一项，复用财务时间范围、季度/年度切换和空状态。百分比指标使用折线图，
避免与亿元金额柱图混淆。

## 错误处理

- 估值源与财务分析源异常分别捕获并记录包含 symbol 的日志。
- 不吞异常含义：同步结果和 `sync_state.warning_message` 返回可定位的短提示。
- 外部失败不删除既有指标，也不把缺失值写为零。
- schema 迁移失败时立即抛错，避免在部分分片结构不一致时继续写入。

## 测试与验收

后端覆盖：

- 新建和旧版分片都会得到四个新列。
- 日线 upsert、重复更新、读取与旧表迁移保留四项估值。
- 估值 DataFrame 按日期合并，单位转换正确，缺失和异常不破坏 OHLCV。
- 财务分析 DataFrame 正确解析四项指标及报告类型。
- 详情 payload 返回新增日线字段和九项财务序列。

前端覆盖：

- K 线图例位于右侧并包含四项新指标。
- 四项估值使用独立轴，缺失值保持 `null`。
- 财务页显示四个新页签且百分比指标使用折线图。
- 原有行情范围、分页、财务筛选和空状态不回归。
