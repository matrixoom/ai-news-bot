
# 最核心的一组

如果你是做宏观分析、财经网站或投资观察，建议先搭建这 15 个核心指标：

| 类别 | 核心指标                 |
| -- | -------------------- |
| 增长 | GDP、工业增加值、服务业生产指数    |
| 消费 | 社会消费品零售总额            |
| 投资 | 固定资产投资、房地产开发投资       |
| 外贸 | 出口、进口                |
| 价格 | CPI、PPI、GDP平减指数      |
| 景气 | 制造业PMI、非制造业PMI       |
| 金融 | 社融、M1、M2、新增人民币贷款     |
| 就业 | 城镇调查失业率              |
| 财政 | 公共财政收入、公共财政支出、政府债券发行 |
| 企业 | 工业企业利润、产成品存货         |
| 市场 | 10年期国债收益率、人民币汇率、主要股指 |

# 一个实用观察框架

可以按这条链路看：
PMI / 社融领先 → 工业增加值 / 社零 / 投资验证 → CPI / PPI / 利润反映结果 → 债券 / 股票 / 汇率定价预期

简单说：

阶段	看什么
领先信号	PMI、社融、M1、新订单
实体验证	工业增加值、社零、投资、出口
价格结果	CPI、PPI、GDP平减指数
企业结果	工业利润、库存、应收账款
市场反应	股指、债券收益率、汇率、商品

如果你是搭建“趋势洞察”这类宏观模块，建议第一版不要贪多，先做：

GDP、PMI、CPI、PPI、社融、M1/M2、工业增加值、社零、固定资产投资、房地产投资、出口、进口、失业率、工业利润、10年国债收益率。

这组指标已经能覆盖 增长、需求、价格、信用、就业、利润、市场预期 七个核心维度。

| 维度       | 核心问题           | 主要对应指标                         | 辅助观察指标                                   |
| -------- | -------------- | ------------------------------ | ---------------------------------------- |
| **增长**   | 经济整体是在加速还是放缓？  | GDP、工业增加值、服务业生产指数              | PMI生产指数、发电量、货运量                          |
| **需求**   | 消费、投资、出口强不强？   | 社会消费品零售总额、固定资产投资、房地产开发投资、出口、进口 | 商品房销售面积、制造业投资、基建投资、汽车零售、餐饮收入             |
| **价格**   | 有没有通胀或通缩压力？    | CPI、PPI、GDP平减指数                | 核心CPI、食品CPI、服务CPI、PPI生产资料、PPI生活资料、大宗商品价格 |
| **信用**   | 钱有没有进入实体经济？    | 社融、M1、M2、新增人民币贷款               | 企业中长期贷款、居民中长期贷款、政府债券融资、M1-M2剪刀差          |
| **就业**   | 居民收入和就业压力如何？   | 城镇调查失业率                        | 青年失业率、居民可支配收入、工资性收入、PMI从业人员指数            |
| **利润**   | 企业赚不赚钱？盈利周期如何？ | 工业企业利润                         | 营业收入、利润率、产成品存货、应收账款、PPI、工业增加值            |
| **市场预期** | 资本市场如何定价未来？    | 10年期国债收益率、人民币汇率、主要股指           | 股债风险溢价、信用利差、商品价格、北向/外资流向、美元指数            |




# 核心宏观指标官方发布维度表

| 类别 | 指标                |         官方基础发布维度 | 是否有季度口径 | 是否有年度口径 | 说明                                            |
| -- | ----------------- | ---------------: | ------: | ------: | --------------------------------------------- |
| 增长 | GDP               |           **季度** |       有 |       有 | 中国 GDP 官方核心发布是季度核算，同时有年度 GDP。月度没有 GDP。        |
| 增长 | 工业增加值             |           **月度** |       有 |       有 | 国家统计局常按“当月”或“1—N 月累计”发布规模以上工业增加值。1—2 月通常合并发布。 |
| 增长 | 服务业生产指数           |           **月度** |       有 |       有 | 通常在月度国民经济运行数据中发布，也会在季度经济运行稿中汇总表述。             |
| 消费 | 社会消费品零售总额         |           **月度** |       有 |       有 | 月度发布当月和累计值，例如“3 月份”“1—3 月份”。                  |
| 投资 | 固定资产投资            |         **月度累计** |       有 |       有 | 官方通常发布“1—N 月固定资产投资”，不是单独只看某一个月绝对额。            |
| 投资 | 房地产开发投资           |         **月度累计** |       有 |       有 | 通常发布“1—N 月全国房地产市场基本情况”，包括开发投资、销售、新开工、施工、竣工等。  |
| 外贸 | 出口                |           **月度** |       有 |       有 | 海关总署有月度表，也有年度表。                               |
| 外贸 | 进口                |           **月度** |       有 |       有 | 同出口，月度、累计、年度都有。                               |
| 价格 | CPI               |           **月度** |       有 |       有 | 每月发布当月同比、环比，也发布“1—N 月平均”。                     |
| 价格 | PPI               |           **月度** |       有 |       有 | 每月发布工业生产者出厂价格和购进价格，当月同比、环比及累计平均。              |
| 价格 | GDP 平减指数          |      **季度/年度派生** |       有 |       有 | 由名义 GDP 和实际 GDP 推算，月度没有。常用于季度、年度分析。           |
| 景气 | 制造业 PMI           |           **月度** |       有 |       有 | 每月发布，50 为荣枯线。季度、年度通常可用月度均值汇总。                 |
| 景气 | 非制造业 PMI / 商务活动指数 |           **月度** |       有 |       有 | 每月发布，包括服务业、建筑业相关景气指标。                         |
| 金融 | 社会融资规模            |           **月度** |       有 |       有 | 央行每月发布社融增量、存量数据；也有季度累计、年度累计。                  |
| 金融 | M1                |           **月度** |       有 |       有 | 央行月度金融统计数据发布。                                 |
| 金融 | M2                |           **月度** |       有 |       有 | 同 M1，月度为主，季度和年度可取期末值或平均值。                     |
| 金融 | 新增人民币贷款           |           **月度** |       有 |       有 | 央行月度发布，通常同时看当月新增和累计新增。                        |
| 就业 | 城镇调查失业率           |           **月度** |       有 |       有 | 国家统计局月度发布，季度经济运行稿中也会公布季度平均值。                  |
| 财政 | 一般公共预算收入          |         **月度累计** |       有 |       有 | 财政部通常发布“1—N 月财政收支情况”，季度就是“1—3 月”等累计口径。        |
| 财政 | 一般公共预算支出          |         **月度累计** |       有 |       有 | 同财政收入。                                        |
| 财政 | 政府债券发行            |      **月度/日度明细** |       有 |       有 | 宏观分析常看月度净融资、发行额；债券本身有逐日发行明细。                  |
| 企业 | 工业企业利润            |         **月度累计** |       有 |       有 | 国家统计局通常发布“1—N 月规模以上工业企业利润”。1—2 月合并发布较常见。      |
| 企业 | 产成品存货             |     **月度累计/期末值** |       有 |       有 | 通常在工业企业利润数据中作为期末存货、应收账款等指标出现。                 |
| 市场 | 10 年期国债收益率        |       **日度/交易日** |     可汇总 |     可汇总 | 中债收益率曲线每个工作日发布，宏观分析可转为月均、季均、年均。               |
| 市场 | 人民币汇率             |       **日度/交易日** |     可汇总 |     可汇总 | 人民币中间价、即期汇率通常按交易日发布。                          |
| 市场 | 主要股指              | **日度/交易日，盘中更高频** |     可汇总 |     可汇总 | 上证指数、沪深 300 等市场行情是交易日数据，可派生月度、季度、年度涨跌幅。       |




| 数据频率 | 建议放哪些指标                                                               |
| ---- | --------------------------------------------------------------------- |
| 日度表  | 国债收益率、人民币汇率、股票指数、商品价格                                                 |
| 月度表  | CPI、PPI、PMI、工业增加值、社零、固定资产投资、房地产投资、出口、进口、社融、M1、M2、新增贷款、失业率、财政收支、工业企业利润 |
| 季度表  | GDP、GDP 平减指数、居民收入、季度就业平均值、季度宏观汇总指标                                    |
| 年度表  | 年度 GDP、人口、居民收入、财政决算、年度 CPI/PPI/PMI 均值、年度进出口、年度投资和消费                   |
