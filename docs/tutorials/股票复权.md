复权主要是为了解决一个问题：**股票发生分红、送股、转增、配股之后，价格会被除权除息，K线图上会出现“人为断层”，直接看不利于判断真实涨跌。**

---

## 1. 什么是不复权？

**不复权 = 使用交易所当天真实成交价格，不做任何历史价格调整。**

比如某股票昨天收盘价是 100 元，今天每 10 股送 10 股，除权后理论价格变成 50 元。

不复权K线会显示：

```text
昨天：100 元
今天：50 元
```

看起来像跌了 50%，但实际上你持有的股数翻倍了，资产价值并没有腰斩。

所以：

```text
不复权价格 = 当天市场真实成交价
```

优点：

```text
真实反映当时市场交易价格
适合看历史实际价格区间、成交价格、挂单价格
```

缺点：

```text
遇到分红、送股、转增后，K线会断裂
不适合直接看长期走势和技术指标
```

---

## 2. 什么是复权？

**复权 = 把分红、送股、转增、配股等因素调整进历史价格，让K线走势更连续。**

复权不是改变真实成交价，而是为了让你更容易看清：

```text
这只股票长期到底涨了多少？
趋势是不是连续？
均线、涨幅、收益率怎么计算更合理？
```

复权主要分两种：

```text
前复权
后复权
```

---

## 3. 什么是前复权？

**前复权 = 保持最新价格不变，把历史价格向下调整。**

这是A股软件里最常用的看盘方式。

假设一只股票：

```text
除权前价格：100 元
10送10后价格：50 元
```

前复权会把过去的 100 元调整成 50 元附近，让K线连续。

也就是：

```text
现在价格不动
过去价格往前修正
```

所以前复权适合看：

```text
当前股价处在历史什么位置
长期趋势
均线
技术分析
阶段涨跌幅
```

前复权的特点：

```text
最新价格 = 真实市场价格
历史价格 = 被调整过
```

例如你现在看到某股票前复权价格是：

```text
当前：20 元
历史低点：2 元
历史高点：30 元
```

那么当前 20 元是真实价格，历史的 2 元、30 元是经过复权调整后的价格，不一定是当时真实成交价。

---

## 4. 什么是后复权？

**后复权 = 保持最早价格不变，把后面的价格向上调整。**

还是刚才例子：

```text
除权前：100 元
除权后：50 元
```

后复权不会把过去的 100 元改掉，而是把之后的价格按照送股、分红因素向上调整。

也就是：

```text
过去价格不动
现在价格往后修正
```

后复权适合看：

```text
长期累计收益
一只股票从上市到现在真实增长了多少
长期持有收益模拟
十倍股、百倍股走势
```

后复权的特点：

```text
历史初始价格 = 接近真实市场价格
当前价格 = 被复权放大后的价格
```

所以你经常会看到一些股票后复权价格很夸张，比如几百元、几千元，这不代表现在真实股价是这么多，而是把历次分红、送转都累计折算进去了。

---

## 5. 三者对比

| 类型  | 调整方式   | 最新价格是否真实 | 历史价格是否真实 | 适合用途            |
| --- | ------ | -------: | -------: | --------------- |
| 不复权 | 不调整    |        是 |        是 | 看真实成交价、历史实际价格   |
| 前复权 | 调整历史价格 |        是 |        否 | 看当前股价位置、趋势、技术分析 |
| 后复权 | 调整后续价格 |        否 |    早期较真实 | 看长期累计收益、长期持有回报  |

---

## 6. 一个简单例子

假设某股票：

```text
第1天：100 元
第2天：10送10，除权后价格变成 50 元
第3天：涨到 60 元
```

### 不复权

```text
第1天：100
第2天：50
第3天：60
```

看起来第2天暴跌，但其实是除权造成的。

### 前复权

```text
第1天：50
第2天：50
第3天：60
```

走势连续，方便看技术图形。当前 60 元是真实价格。

### 后复权

```text
第1天：100
第2天：100
第3天：120
```

方便看长期收益：从 100 到 120，实际收益是 20%。

---

## 7. 实战中怎么看？

一般建议：

```text
看盘、画趋势线、看均线：用前复权
看真实历史成交价：用不复权
看长期累计涨幅、长期持有收益：用后复权
```

对你的 TrendInsight 系统来说，如果是拉取A股日线数据，建议数据库中至少保留：

```text
原始价格：open/high/low/close，不复权
前复权价格：qfq_open/qfq_high/qfq_low/qfq_close
后复权价格：hfq_open/hfq_high/hfq_low/hfq_close，可选
复权因子：adjust_factor
```

更专业的做法是：**底层保存不复权原始价格 + 复权因子，前端或分析层按需计算前复权/后复权价格。**这样数据最干净，也方便后续策略回测。
