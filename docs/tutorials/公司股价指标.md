除了**市盈率 PE**、**市净率 PB**，分析一只股票通常还要看这几类关键指标。

## 一、估值指标

| 指标        | 含义            | 主要看什么            |
| --------- | ------------- | ---------------- |
| PE 市盈率    | 股价 / 每股收益     | 盈利估值，适合盈利稳定公司    |
| PB 市净率    | 股价 / 每股净资产    | 资产估值，适合银行、地产、周期股 |
| PS 市销率    | 总市值 / 营业收入    | 适合亏损但有收入增长的公司    |
| PEG       | PE / 净利润增速    | 判断估值和成长是否匹配      |
| 股息率       | 每股分红 / 股价     | 看分红回报，适合高股息公司    |
| EV/EBITDA | 企业价值 / EBITDA | 常用于重资产、跨公司比较     |

最常用组合：

```text
PE + PB + 股息率 + PEG
```

---

## 二、盈利能力指标

| 指标       | 含义        | 主要看什么       |
| -------- | --------- | ----------- |
| ROE      | 净利润 / 净资产 | 股东回报能力，核心指标 |
| ROA      | 净利润 / 总资产 | 资产赚钱效率      |
| 毛利率      | 毛利润 / 营收  | 产品或服务赚钱能力   |
| 净利率      | 净利润 / 营收  | 最终利润转化能力    |
| 净资产收益率变化 | ROE 同比/环比 | 盈利质量是否改善或恶化 |

这里面最重要的是：

```text
ROE
```

一般来说，长期优秀公司通常有持续较高、较稳定的 ROE。

---

## 三、成长指标

| 指标       | 含义            | 主要看什么    |
| -------- | ------------- | -------- |
| 营收同比增长率  | 本期营收相对去年增长    | 主营业务是否扩张 |
| 净利润同比增长率 | 本期利润相对去年增长    | 盈利是否增长   |
| 扣非净利润增长率 | 剔除非经常损益后的利润增长 | 主业真实增长   |
| 经营现金流增长率 | 经营现金流同比增长     | 增长质量     |
| EPS 增长率  | 每股收益增长        | 股东收益增长   |

重点看：

```text
营收增速 + 扣非净利润增速 + 经营现金流增速
```

如果利润增长很快，但营收不增长、现金流很差，就要警惕利润质量。

---

## 四、财务质量指标

| 指标          | 含义            | 主要看什么     |
| ----------- | ------------- | --------- |
| 资产负债率       | 负债 / 总资产      | 杠杆高不高     |
| 有息负债率       | 有息债务 / 总资产或权益 | 偿债压力      |
| 经营现金流净额     | 主业产生的现金       | 利润是否有现金支撑 |
| 经营现金流 / 净利润 | 现金流和利润匹配度     | 利润含金量     |
| 应收账款周转率     | 收款效率          | 是否赊销严重    |
| 存货周转率       | 存货变现效率        | 是否库存积压    |
| 商誉 / 净资产    | 商誉占比          | 并购减值风险    |

最关键的是：

```text
经营现金流 / 净利润
```

如果长期小于 1，说明利润质量可能偏弱。

---

## 五、市场交易指标

| 指标   | 含义              | 主要看什么    |
| ---- | --------------- | -------- |
| 总市值  | 股价 × 总股本        | 公司市场规模   |
| 流通市值 | 股价 × 流通股本       | 实际交易盘子大小 |
| 成交额  | 当日成交金额          | 资金关注度    |
| 换手率  | 成交量 / 流通股本      | 活跃程度     |
| 量比   | 当前成交量 / 过去平均成交量 | 是否放量     |
| 涨跌幅  | 股价变化            | 短期市场表现   |
| 振幅   | 最高价与最低价差异       | 波动强度     |

做股票行情页时，建议至少展示：

```text
总市值、流通市值、成交额、换手率、涨跌幅
```

---

## 六、股东与筹码指标

| 指标        | 含义          | 主要看什么   |
| --------- | ----------- | ------- |
| 股东户数      | 持股账户数量      | 筹码集中或分散 |
| 户均持股      | 总股本 / 股东户数  | 筹码集中度   |
| 前十大股东持股比例 | 大股东集中度      | 控制权稳定性  |
| 北向资金持股    | 外资持仓变化      | 外资偏好    |
| 机构持股比例    | 基金、保险、社保等持股 | 机构认可度   |
| 质押比例      | 股东质押股份比例    | 爆仓或减持风险 |

A股里比较有用的是：

```text
股东户数变化 + 机构持仓变化 + 质押比例
```

# 如果做你的股票详情页，我建议核心指标分成 6 组

```text
股票概览
  ├── 当前价格
  ├── 涨跌幅
  ├── 总市值
  ├── 流通市值
  ├── 成交额
  └── 换手率

估值指标
  ├── PE
  ├── PB
  ├── PS
  ├── PEG
  └── 股息率

盈利能力
  ├── ROE
  ├── ROA
  ├── 毛利率
  ├── 净利率
  └── 扣非净利率

成长能力
  ├── 营收同比
  ├── 净利润同比
  ├── 扣非净利润同比
  └── 经营现金流同比

财务质量
  ├── 资产负债率
  ├── 经营现金流 / 净利润
  ├── 应收账款周转率
  ├── 存货周转率
  └── 商誉 / 净资产

筹码结构
  ├── 股东户数
  ├── 机构持股比例
  ├── 北向资金持股
  └── 质押比例
```

第一版最小可行可以先做这 12 个：

```text
PE
PB
PS
股息率
ROE
毛利率
净利率
营收同比
净利润同比
资产负债率
经营现金流 / 净利润
总市值
```

这套指标已经能覆盖：**贵不贵、赚不赚钱、增长快不快、财务稳不稳、市场给多少估值**。
