# Task 05: Macro Indicators Monitoring

## 目标

新增宏观经济指标监测模块，支持后续持续扩展。

## 第一版关注指标

建议第一版不要一次铺太多，优先做“数据可稳定拿到、口径相对明确”的指标：

- CPI
- PPI
- 名义 GDP
- 实际 GDP
- 社会融资或货币相关代表性指标
- 居民杠杆率
- 政府杠杆率

“股民存款”这类指标要先确认是否有稳定、公开、可持续获取的数据口径，不能先写进核心交付承诺。

## 设计原则

- 宏观模块必须围绕“指标定义、来源、频率、最新值、上期值、趋势、发布时间”展开
- 不能只有数字，没有口径说明

## 任务拆解

### 1. 指标注册表

建议建立指标注册机制，每个指标定义：

- 名称
- 频率
- 单位
- 来源
- 更新规则
- 抓取 provider
- 展示格式

### 2. 数据获取与标准化

需要处理：

- 月度、季度、年度频率不同
- 官方发布时间不一致
- 缺失值和口径变化

### 3. 趋势视图

第一版至少支持：

- 最新值
- 上期值
- 同比 / 环比
- 简短趋势判断

### 4. 页面展示

建议采用卡片 + 小表格模式，不要一开始做复杂图表依赖。

## 本阶段交付

- 宏观指标清单
- 指标注册表设计
- 数据标准化方案
- 页面展示协议

## 验收标准

- 新增一个宏观指标只需配置和 provider 增补，不必改核心页面逻辑
- 每个指标都有来源和更新时间
- 无法取数时页面有降级显示

## 难点

- 指标更新频率差异大
- 某些指标可能没有稳定免费 API，只能走官方页面解析
